# Smart Industrial Load-Shedding System: 30% Energy Bill Reduction

## Overview
An end-to-end IoT solution designed to reduce industrial electricity costs by monitoring real-time power consumption and automating load-shedding during peak hours or threshold breaches.

## Key Features
* **Real-Time Monitoring:** High-accuracy AC current sensing using SCT-013.
* **Intelligent Load Shedding:** Automated logic to disconnect non-critical loads to avoid peak-demand penalties.
* **Remote Analytics:** Cloud-integrated dashboard for live kW tracking and historical data.
* **Instant Alerts:** Telegram Bot integration for real-time system status and emergency notifications.

## Tech Stack
* **Hardware:** ESP32, SCT-013 Current Sensors, Relay Modules, LCD I2C.
* **Firmware:** Embedded C++ (Arduino Framework / ESP-IDF).
* **Protocols:** MQTT, HTTP, Telegram API.
* **Tools:** Altium/EasyEDA (Schematics), Blynk/Custom Dashboard.

## Results
* **20%-30%** reduction in monthly energy bills.
* Zero-downtime installation using non-invasive sensing.
